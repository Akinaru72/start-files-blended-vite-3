# Countries App

Застосунок для пошуку та перегляду інформації про країни з використанням
[REST Countries API](https://restcountries.com/).

## Функціонал

### Маршрутизація

У застосунку реалізовано такі маршрути:

- `/` — сторінка **Home**, відображає перелік країн Європи
- `/country` — сторінка **SearchCountry**, пошук країн за регіоном
- `/country/:countryId` — сторінка **Country**, детальна інформація про країну

Для неіснуючих маршрутів використовується перенаправлення на головну сторінку за
допомогою компонента `<Navigate />`.

Сторінки завантажуються відкладено з використанням `React.lazy`.

---

## API

Для роботи з бекендом використовуються функції з файлу `service/countryApi`.

Використані ендпоінти REST Countries API:

- `/v3.1/region/europe` — отримання списку країн Європи
- `/v3.1/region/{region}` — пошук країн за регіоном
- `/v3.1/name/{name}` — отримання детальної інформації про країну

---

## Сторінки

### Home

При завантаженні сторінки виконується запит за країнами Європи. Список країн
відображається за допомогою компонента `CountryList`, який використовує
компоненти `Grid` та `GridItem`.

---

### SearchCountry

На сторінці підключено форму `<SearchForm />` для вибору регіону. Після сабміту
виконується запит за країнами вибраного регіону. Результати відображаються через
компонент `CountryList`.

---

### Country

Сторінка відображає детальну інформацію про вибрану країну. Реалізовано кнопку
повернення назад за допомогою компонента `GoBackBtn`.
